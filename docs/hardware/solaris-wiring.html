Solaris device wiring

The Solaris device is one ESP32 with an RS485 transceiver. It plugs into the hybrid inverter's communication port, reads its Modbus registers every few seconds, and publishes them to the server laptop over Wi-Fi. A kWh smart meter can share the same two-wire bus.

Wiring

Solaris only touches the inverter's low-voltage communication port. Hover a row in the pin tables to trace its wire. Pin positions differ between ESP32 boards, so follow the GPIO numbers.

The inverter's A and B go to the module's A and B over a twisted pair. The ESP32 drives the module: TX → DI, RO → RX, and GPIO4 switches it between sending and listening.

The SDM120 joins the same pair (A to A, B to B) as slave 2. The Solaris device polls both each cycle and publishes the meter on /meter.

Teach Solaris your inverter

Every brand keeps its readings at different Modbus addresses. Copy the simulator profile in firmware/solaris-device/profiles.h, fill in the eight registers from the inverter's Modbus manual, then point config.h at it.

// profiles.h: name, slave id, baud, function (3 = holding, 4 = input), grid-on threshold
static const BrandProfile PROFILE_MY_INVERTER = {
  "my-inverter", 1, 9600, 3, 150.0f,      // grid_on from grid voltage: above 150 V = grid up
  {
    /* pv_w       */ { 186, 1.0f, false },   // register, scale, signed?  (example numbers:
    /* load_w     */ { 178, 1.0f, false },   //  take yours from the manual)
    /* grid_w     */ { 169, 1.0f, true  },   // + import, − export
    /* batt_soc   */ { 184, 1.0f, false },
    /* batt_w     */ { 190, 1.0f, true  },   // + discharging, − charging
    /* grid_on    */ { 150, 0.1f, false },
    /* inv_temp_c */ {  90, 0.1f, true  },
    /* fault_code */ { 103, 1.0f, false },
  }
};

// config.h
#define PROFILE        PROFILE_MY_INVERTER
#define RS485_DE_PIN   4

Status light

The on-board LED (GPIO2) says what's wrong without a laptop.

Fast blink · no Wi-Fi
Slow blink · no MQTT broker
Double blink · inverter or meter not answering
Solid · all good (flicks off on each publish)

First power-up

  1. Find the inverter's Modbus settings in its menu or manual: slave ID (usually 1), baud (usually 9600, 8N1) and which port pins carry A and B.
  2. In solaris-device/config.h set WIFI_SSID, WIFI_PASS, DEVICE_ID (solaris-001), the laptop's name in MQTT_MDNS_HOST, and your PROFILE.
  3. Flash the ESP32 as ESP32 Dev Module, wire it as above, and power it from USB.
  4. Start Mosquitto and the server on the laptop. Readings on solaris/solaris-001/telemetry should match the inverter's own screen.

No reply? Check the shared ground, swap A and B, then check the slave ID and baud. The serial monitor prints a hint for each read error.

Safety. Solaris connects only to the inverter's communication port, which is low voltage. Never open the inverter or touch its PV, battery or AC terminals: those carry dangerous DC and mains voltage even when the grid is off. For a permanent installation, use an isolated RS485 transceiver and have a licensed electrician check the setup.
